## Source discipline

1. Record title, section heading, edition/revision, and URL before quoting.
2. Determine rights separately for the underlying historical work and the inspected site's transcription/editorial layer. Do not infer that a site transcription is unrestricted merely because the ancient original is public domain.
3. Paraphrase independently by default. This repository does not copy or redistribute Wikisource/CText transcription text, punctuation, annotations, or editorial prose.
4. Quote only when necessary, within the applicable source/license limits, and label commentary separately from base text.
5. Preserve variant rules under distinct IDs.
6. Mark an unattributed modern internet table `UNVERIFIED`; do not use it in a material conclusion.
7. Keep 《果老星宗》 and other non-Four-Pillars systems outside the core unless the user explicitly asks for a separate comparison.

## Method namespaces

- `CAL-*`: calendrical convention, never a life prediction.
- `T-HOU-*`: 调候.
- `F-YI-*`: 扶抑.
- `GE-JU-*`: 格局/相神.
- `B-YAO-*`: 病药.
- `SHEN-*`: 神煞, disabled by default.
- `REFLECT-*`: modern low-risk reflection, not a classical claim.
